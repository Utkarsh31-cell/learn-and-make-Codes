Course Structure:


1. What Is Networking?

Learn:

LAN, WAN, MAN, PAN
Internet vs Intranet
Client-server model
Peer-to-peer
Bandwidth vs latency
Throughput
Packet switching

Understand how data travels from one computer to another.

========================================================================================================================================

2. OSI Model (VERY IMPORTANT)

You must master all 7 layers.

OSI Layers:

 7−Application, 6−Presentation, 5−Session, 4−Transport, 3−Network, 2−Data Link, 1−Physical

Learn:

Layer	       Devices	        Protocols
Application	   Proxy	        HTTP, DNS
Transport	   Firewall	        TCP, UDP
Network	       Router	        IP, ICMP
Data Link	   Switch	        Ethernet
Physical	   Hub	            Cables

You should be able to troubleshoot using OSI.

========================================================================================================================================

3. TCP/IP Model

| TCP                 | UDP               |
| ------------------- | ----------------- |
| Reliable            | Fast              |
| Connection-oriented | Connectionless    |
| ACK                 | No ACK            |
| Used in HTTPS       | Used in Streaming |
